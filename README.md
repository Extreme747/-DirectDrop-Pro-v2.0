## 🚀 Key Features in v4.0

### 1. ▶ YouTube AdBlocker & Fast-Skip
- **Instant Ad Skip:** Auto-clicks skip buttons within milliseconds.
- **Fast-Forward Ads:** Accelerates video ads to 16x speed, mutes audio, and fast-forwards directly to the end.
- **Anti-Adblock Popup Destroyer:** Automatically removes YouTube's "Ad blockers violate YouTube's Terms of Service" modal dialog and resumes video playback seamlessly.
- **Focus Mode:** Option to hide addictive YouTube Shorts shelves and navigation.

### 2. ⚡ Dev Swiss-Knife & Scratchpad
Access a full developer workspace directly on any tab:
- **📝 Scratchpad:** Auto-saved Markdown and code scratchpad persisted locally.
- **🔧 JSON Tool:** Format (Beautify) / Minify / Validate ugly JSON.
- **🔐 JWT Decoder:** Decodes JWT headers and payload payloads instantly.
- **📦 Base64 Tool:** 1-Click Encode & Decode.
- **🆔 UUID v4:** Instant UUID generation with 1-click copy.
- **🧠 30-Second Page TL;DR:** Summarizes any technical doc or blog into 3 core bullet points.

### 3. 🧪 1-Click Mock Form Auto-Filler
- Automatically populates web forms with realistic test data (Name, Email, Phone, Strong Password, Company, Address) and triggers synthetic events for React, Vue, and Angular apps.

### 4. 🐙 GitHub Power Actions
- On any GitHub repo page:
  - **`💻 github.dev`**: Opens repo directly in Web VS Code.
  - **`📋 Clone`**: Copies `git clone https://github.com/...` command to clipboard.

### 5. 🔕 Silent Ninja Mode (No Toast Spam)
- Background traps and timers bypass quietly without cluttering your screen with toasts.

### 6. 📦 Batch Link Grabber, Headless Exporter & Webhooks
- Quality filter tabs (`[4K]`, `[1080p]`, `[720p]`, `[480p]`).
- Export ready-to-run **Python downloader scripts** (`download_script.py`) and **Bash scripts** (`aria2c`).
- 1-Click dispatch to Discord Webhooks, VPS, or local Motrix/Aria2 RPC.
