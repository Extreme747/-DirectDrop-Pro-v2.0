## 🚀 Key Highlights in v3.5 Dev Edition

- **🔕 Silent Ninja Mode (No Toast Spam):**
  Completely silences on-screen notifications. Timer accelerations and trap removals happen quietly in the background without cluttering your browser screen.
  
- **🐍 Headless Script Exporter (Python & Bash/aria2c):**
  Batch Grabber now exports fully configured **Python scripts** (`download_script.py` with multi-threading and resume) or **Bash scripts** (`download.sh` with `aria2c -j 4 -x 4`). Perfect for copying and running directly on your Linux VPS, Docker, or server.

- **📡 Webhook Dispatcher (Discord, Telegram, R2, n8n):**
  Push extracted direct links straight to a Discord webhook, Cloudflare Worker, or custom server endpoint with 1 click.

- **🕵️ Web Asset & API Sniffer:**
  Developer tool that inspects the active page and extracts all **SVG icons**, **Fonts**, **High-res images**, and hidden **Next.js/Nuxt state and API endpoints**.

- **🎛️ Quality Filter Tabs & Aria2 RPC:**
  Filters links by `[4K]`, `[1080p]`, `[720p]`, `[480p]`, with 1-click dispatch to Motrix/Aria2 RPC (`http://localhost:6800/jsonrpc`).

- **🛡️ Server Whitelisting & Anti-Anti-AdBlocker:**
  Zero false positives on HubCloud, GamerX, FSL Server, PixelServer, BuzzServer, MediaFire, Mega, GDrive, and 1fichier.
